# Haor Duck Farming: Climate-Smart Practices and Flood Resilience (ML)

Binary classification project on duck farming in Bangladesh's haor wetlands. It follows the
structure of [Telco-Customer-Churn-ML](https://github.com/anesriad/Telco-Customer-Churn-ML):
scikit-learn / XGBoost, MLflow tracking, a FastAPI service, a Gradio input form, Docker and CI.

**Question:** given a farmer's profile and the climate-smart practices adopted, will flood-season
duck mortality stay at or below 15%? (`low_mortality`)

> **Data status.** The real survey data (300 farmers, Mohanganj, Netrokona) contains personal
> details and is **not** in this repository. Everything here runs on a clearly labelled
> **synthetic** dataset (`data/synthetic/`), generated by `scripts/make_synthetic_data.py`.
> Results from it are for learning only and must not be reported as findings.

## Run it
```bash
python -m venv .venv && .venv\Scripts\activate    # Windows
pip install -r requirements.txt
python scripts/make_synthetic_data.py             # optional, regenerates the CSV
python scripts/train.py                           # compares models, logs to MLflow, saves models/model.joblib
pytest -q
uvicorn app.main:app --app-dir src --port 8000    # form at http://localhost:8000/ui
```
`POST /predict` takes the fields shown in `src/app/main.py`; `GET /` is a health check.
Docker: `docker build -t haor-duck . && docker run -p 8000:8000 haor-duck`.

## Layout
`scripts/` data generator + training · `src/serving/` features and model · `src/app/` API and UI ·
`tests/` · `.github/workflows/ci.yml`
